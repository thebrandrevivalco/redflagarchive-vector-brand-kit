Red Flag Archive — Vector Brand Kit

The logo and badge set for my Etsy shop, Red Flag Archive. All drawn in Inkscape, all vector, 
so nothing goes blurry when I resize it for a listing photo or a social post.
I made this because my old logo was a PNG I'd stretched one too many times and it showed.

What's in here:

- `svg/rfa-flag-logo.svg` — the main logo (flag + wordmark)
- `svg/instant-download-badge.svg` — the yellow seal I put on listing photos
- `svg/new-starburst-badge.svg` — starburst for new product drops
- `svg/red-flag-icon.svg` / `svg/yellow-flag-icon.svg` — plain flag icons, used everywhere
- `png/` — 1024px exports of each, ready to drop into GIMP

Brand colors:

- Hot pink `#FF0A54`
- Acid yellow `#FFE600`
- Near black `#090607`

Hard shadows, flat colors, no gradients. That's the look — punk flyer, not wedding invitation.

Notes to self
- Headline font is an Impact-style stack. If it ever renders in a serif, the font fell back — check before exporting.
- The badge text sits close to the ring on purpose. Don't "fix" it again, it took three tries to get it readable at thumbnail size.
